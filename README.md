# LLM Evaluation & Auditing Toolkit 🚀

## Overview
This repository contains the foundational structure for a web-based utility application designed to streamline the evaluation, preprocessing, and safety auditing of Large Language Model (LLM) outputs. 

This tool is currently in the active planning and early development phase, and it will also serve as a core component of my Computer Science graduation project. The goal is to replace tedious manual evaluation processes with an automated, UI-driven workflow.

## Core Objectives
- **Automated Data Parsing:** Efficiently parse and clean raw JSON and text datasets.
- **Side-by-Side Comparison UI:** Provide a user-friendly web interface for human evaluators to compare model outputs seamlessly.
- **Safety & Toxicity Auditing:** Integrate custom formatting checks and auditing logic to flag potential safety violations in AI responses.

## Proposed Tech Stack
- **Data Processing:** Python, Pandas, Regex
- **Frontend Framework:** Streamlit
- **Development & AI Assistance:** Claude Code (planned for accelerating UI development and complex logic integration)

## Current Status
🚧 **Work in Progress:** I am currently establishing the project architecture, defining data pipelines, and structuring the evaluation criteria. The main functional codebase and initial Streamlit components will be pushed in upcoming commits as the development phase officially begins.
